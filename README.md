# 🦜 PollyGlot AI Translator

An intelligent translation tool that leverages the power of **Google Gemini 3 API** to provide accurate and instant translations.

## ✨ Features
* **AI-Powered:** Uses the latest `gemini-3-flash-preview` model.
* **Fast & Responsive:** Built with a Node.js backend for secure API handling.
* **User-Friendly UI:** Simple language selection (French, Spanish, Japanese) and a "Start Over" feature.

## 🚀 Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Backend:** Node.js, Express.js
* **AI Integration:** Google Generative AI SDK

## 🛠️ Setup
1. Clone the repo.
2. Run `npm install` to get dependencies like `express` and `cors`.
3. Create a `.env` file with your `API_KEY`.
4. Start the server with `node server.js`.
